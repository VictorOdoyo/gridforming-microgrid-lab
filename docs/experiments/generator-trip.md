# Generation contingency

At 2 seconds the second inverter disconnects. The first source supplies the
remaining impedance load. Secondary control observes only enabled sources.
The disconnected inverter's state is frozen; its reported internal frequency is
therefore not a measurement of an energized terminal.

Evaluate survivor frequency, source current, bus voltage, and algebraic residual.
This experiment assumes adequate DC energy; it does not certify battery autonomy.
